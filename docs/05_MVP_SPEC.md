# Seller CFO — MVP Specification

## MVP Goal

Пользователь подключает Wildberries и за 5 минут получает:

1. Реальную прибыль.
2. Реальную маржу.
3. Основные расходы.
4. Найденные финансовые аномалии.
5. Риск кассового разрыва.

# Success Criteria

MVP считается успешным если:

1. User connects API.
2. Data sync completes.
3. Financial metrics calculate.
4. At least one actionable insight can be generated.
5. User understands why the insight appeared.
6. User can identify potential money loss.
